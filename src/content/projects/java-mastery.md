## The brief

Java is the core language of my degree. I wanted one place that takes a beginner from their first program to writing well-structured, object-oriented code, and that I could use to revise along the way.

## The work

The course runs in nine modules across three levels. **Foundations** covers an introduction to Java, data types and operators, control flow and arrays. **OOP** covers classes and objects, then inheritance and polymorphism. **Advanced** covers exceptions and I/O, the Collections Framework and design patterns.

Every module has a Learn view and a Quiz view. Progress is saved in your browser, so the sidebar always shows how far you've come. It's a single static page with no build step, hosted on GitHub Pages, and you can try it right here.
