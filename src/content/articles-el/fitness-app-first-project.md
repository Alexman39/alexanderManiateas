Όταν ξεκίνησα να γράφω κώδικα, ήξερα ότι ήθελα το πρώτο μου πραγματικό project να είναι κάτι προσωπικό, κάτι με το οποίο θα επέμενα. Ως κάποιος που αγαπά και το fitness και την τεχνολογία, ήταν λογικό να τα συνδυάσω. Έτσι ξεκίνησα να φτιάχνω μια εφαρμογή καταγραφής προπόνησης, όχι μόνο για να μάθω, αλλά για να φτιάξω κάτι πραγματικά χρήσιμο.

Αυτό το project μού έδωσε κάτι παραπάνω από εξάσκηση σε HTML, CSS και JavaScript. Με έφερε σε επαφή με:

- Τον σχεδιασμό για πραγματικούς χρήστες
- Το debugging σύνθετων αλληλεπιδράσεων
- Τη δημιουργία διαισθητικών διεπαφών
- Τη σωστή οργάνωση αρχείων και φακέλων

## Τι έμαθα στην πορεία

Αντί να φτιάξω έναν γενικό ιστότοπο, εστίασα στις ανάγκες ανθρώπων σαν εμένα, που ήθελαν να καταγράφουν τις προπονήσεις τους, να βλέπουν την πρόοδό τους και να μένουν συνεπείς. Αυτές είναι οι βασικές λειτουργίες στις οποίες επικεντρώθηκα:

| Λειτουργία | Προτεραιότητα | Όφελος για τον χρήστη | Κατάσταση |
| --- | --- | --- | --- |
| Καταγραφή προπονήσεων | Υψηλή | Καταγράφει τις καθημερινές ασκήσεις | Ολοκληρώθηκε |
| Πίνακας προόδου | Μεσαία | Οπτικοποιεί τη βελτίωση του χρήστη | Σε εξέλιξη |
| Καταγραφή διατροφής | Χαμηλή | Καταγράφει θερμίδες και μακροθρεπτικά | Σχεδιάζεται |
| Responsive σχεδιασμός | Υψηλή | Καλύτερη χρήση στο κινητό | Ολοκληρώθηκε |
