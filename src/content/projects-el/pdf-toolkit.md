## Το ζητούμενο

Οι περισσότεροι δωρεάν ιστότοποι για PDF ανεβάζουν τα έγγραφά σας σε κάποιον server. Για συμβόλαια, μισθοδοσίες ή ιατρικές επιστολές, αυτό είναι πραγματικό κόστος στην ιδιωτικότητα για μια απλή δουλειά. Ήθελα ένα εργαλείο που δεν χρειάζεται καμία εμπιστοσύνη, γιατί δεν υπάρχει πουθενά να πάει ένα αρχείο.

## Η δουλειά

Κάθε λειτουργία τρέχει σε JavaScript πάνω στη δική σας συσκευή. Οι λειτουργίες PDF είναι καθαρές συναρτήσεις, bytes μέσα και bytes έξω, που τρέχουν σε ένα Web Worker, ώστε η σελίδα να μην παγώνει ποτέ με ένα μεγάλο αρχείο, και η Ακύρωση να ελευθερώνει αμέσως τη μνήμη. Το pdf-lib γράφει τα PDF, και το pdf.js αποδίδει τις μικρογραφίες και τις σελίδες για την ισχυρή συμπίεση.

Ελέγχει την κεφαλίδα `%PDF-` αντί να εμπιστεύεται την επέκταση του αρχείου, οπότε τα κατεστραμμένα αρχεία και όσα έχουν κωδικό παίρνουν ένα σαφές μήνυμα αντί για χαλασμένο αποτέλεσμα.

## Ιδιωτικότητα που μπορείτε να ελέγξετε

Το «δεν ανεβάζουμε τα αρχεία σας» είναι εύκολο να το ισχυριστεί κανείς, γι' αυτό η εφαρμογή δεν σας ζητά να το πιστέψετε:

- **Δεν υπάρχει backend.** Ο ιστότοπος είναι ένα σύνολο στατικών αρχείων στο GitHub Pages.
- **Ο browser μπλοκάρει κάθε σύνδεση.** Μια Content Security Policy με `connect-src 'none'` τον κάνει να αρνείται κάθε αίτημα, ακόμη κι αν κάποιος κώδικας δοκίμαζε να το στείλει.
- **Όλες οι βιβλιοθήκες είναι ενσωματωμένες**, χωρίς CDN και χωρίς τρίτους.
- **Ένας έλεγχος το επιβάλλει.** Ένα end-to-end test τρέχει κάθε εργαλείο σε πραγματικό browser και αποτυγχάνει αν η σελίδα κάνει έστω ένα αίτημα δικτύου μετά τη φόρτωση.

Μετά την πρώτη σας επίσκεψη, ένας service worker κρατά ένα αντίγραφο της εφαρμογής, οπότε λειτουργεί ακόμη και με το Wi-Fi κλειστό.

## Φτιαγμένο με φροντίδα

Λειτουργεί μόνο με πληκτρολόγιο, με αναγνώστες οθόνης και με αφή, και ακολουθεί το φωτεινό ή σκούρο θέμα του συστήματός σας. Δεν έχει λογαριασμούς, διαφημίσεις ή analytics.
