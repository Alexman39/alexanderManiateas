## Η ιδέα

Ένας φάκελος Downloads είναι μια μικρή πράξη χάους. Αυτό το εργαλείο φέρνει τάξη με σαφείς κανόνες, και επειδή η μετακίνηση αρχείων δεν αναιρείται εύκολα, δείχνει πάντα μια προεπισκόπηση dry-run με ακριβώς ό,τι θα αλλάξει, πριν αγγίξει οτιδήποτε.

Είναι επίσης μια άσκηση σε καθαρή αντικειμενοστραφή Java: file I/O, αντικείμενα strategy για κάθε κανόνα ταξινόμησης, και δοκιμές που το αποδεικνύουν.
