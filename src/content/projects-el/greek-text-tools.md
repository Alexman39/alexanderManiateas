## Η ιδέα

Κάθε ελληνικό web project πέφτει πάνω στα ίδια μικρά προβλήματα: αναζήτηση που αποτυγχάνει εξαιτίας των τόνων, URLs γεμάτα κωδικοποιημένους χαρακτήρες, χρήστες που γράφουν σε Greeklish. Αυτό το πακέτο τα λύνει μία φορά και σωστά, και συνοδεύεται από σελίδα επίδειξης που θα μπορείτε να δοκιμάσετε εδώ.
